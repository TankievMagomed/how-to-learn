# Проект «Научить учиться»

Проект создан в рамках курса «Веб-разработчик» от Яндекс Практикума для освоения базовых и расширенных возможностей HTML и CSS.

Это одностраничный сайт из нескольких секций. Он демонстрирует освоенные возможности HTML и CSS, а также рассказывает о современных и эффективных подходах к обучению.

## Технологии

- HTML5
- CSS3
- БЭМ
- Flexbox
- CSS-анимации (@keyframes)
- iframe

## Планы по доработке

- подключить другие шрифты
- добавить любимые образовательные видео
- проверить кроссбраузерность и добавить вендорные префиксы
- разработать форму для отправки комментариев
